# ZIP-316: Unified Addresses Reference

**Status**: Standard  
**Official Specification**: [zips.z.cash/zip-0316](https://zips.z.cash/zip-0316)  
**Applicability to Nocturne**: Format of deposit pot addresses and winner return addresses.

---

## 1. Unified Address (UA) Fundamentals

A Unified Address combines multiple receiver types into a single human-readable string:
* **Orchard Receiver**: Modern shielded pool (Halo 2 proof system, no trusted setup).
* **Sapling Receiver**: Legacy shielded pool (`zs...`).
* **Transparent Receiver**: Public pool (`t...`).

---

## 2. Network Prefixes & Encodings

| Network | Human-Readable Prefix (HRP) | Example Pattern |
| :--- | :--- | :--- |
| **Mainnet** | `u1` | `u1...` (bech32m encoded) |
| **Testnet** | `utest1` | `utest1...` (bech32m encoded) |

---

## 3. Strict Rules for Nocturne Markets

1. **Shielded Preference**:
   - The coordinator pot address generated for a market MUST contain an **Orchard receiver** (and optionally Sapling).
   - Deposits from transparent addresses (`t-addr`) compromise user privacy and should be rejected or flagged with a prominent UI warning.
2. **Payout Addresses**:
   - The user must provide a fresh shielded Unified Address or Sapling address for payouts.
   - Payout transactions sent by Nocturne MUST only send to shielded receivers.
